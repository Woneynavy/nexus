# Nexus Home Cleaning

A modern, mobile-friendly one-page website for **Nexus Home Cleaning**, a home and office cleaning company serving homes and small offices across Uyo, Nigeria. The site is built to convert visitors into WhatsApp booking requests.

## Live site

[https://Woneynavy.github.io/nexus/](https://Woneynavy.github.io/nexus/)

## Features

- Hero section with headline and a free-quote request form
- Short business introduction
- Three cleaning services (Home, Office, Deep Cleaning)
- "Why choose us" section (6 trust points)
- Simple pricing packages (Essential, Premium, Office Care)
- Customer testimonials
- Frequently asked questions (FAQ accordion)
- Contact details & working WhatsApp booking buttons with pre-filled messages
- Floating WhatsApp button
- Terms & Conditions and Privacy Policy pages
- Fully responsive, mobile-first design

## Tech stack

- Pure HTML, CSS and vanilla JavaScript — no build tools or frameworks needed
- Google Fonts: Plus Jakarta Sans + Inter
- WhatsApp integration via `https://wa.me/2347064556444`

## Project structure

```
index.html      One-page website
styles.css      All styling (premium design, responsive)
script.js       Mobile nav, quote form -> WhatsApp, interactions
terms.html      Terms & Conditions
privacy.html    Privacy Policy
favicon.svg     Site icon / Open Graph image
```

## Local development

Open `index.html` in any browser. No server or installation required.

## Deploy

Hosted on GitHub Pages (branch `main`, root folder). Push to `main` to auto-publish:

```bash
git add -A
git commit -m "Update site"
git push
```
